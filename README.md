# HanchiaFish - Maritime Surveillance System

A premium maritime monitoring and fleet management application built with Flutter.

## ✨ Features

- **Real-time GPS Tracking**: Live location monitoring of all maritime units.
- **Premium Dashboard**: Glassmorphic UI with advanced metrics visualization.
- **Vision IA Integration**: Live camera surveillance with intelligent detection.
- **Fleet Management**: Comprehensive boat profiles and status tracking.
- **Advanced Analytics**: Detailed trip history and fleet statistics.

## 🚀 Getting Started

This project is deployed to GitHub Pages.

### Local Development

1.  Clone the repository
2.  Run `flutter pub get`
3.  Run `flutter run -d chrome`

## 🛠 Tech Stack

- **Framework**: Flutter (Web/Mobile)
- **Styling**: Material 3 Premium Design System
- **Maps**: Flutter Map (OpenStreetMap)
- **Backend**: API Service Integration
